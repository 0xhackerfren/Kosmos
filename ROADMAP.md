# Roadmap

## Foundation: current implementation

- Explicit world/policy interfaces and registration.
- Versioned numeric genomes, mutation/recombination, genealogy events.
- Resource habitat, lifecycle rules, and deterministic reference policies.
- Trajectory records, complete state checkpoints, and continuation checks.
- A second runnable plugin example and automated CI.

## Next: recover and establish evidence

1. Recover and audit the earlier ECI archive separately.
2. Reconcile useful existing components and revalidate historical pilot artifacts.
3. Run replicated mechanism checks and resource-accounting audits.
4. Define the first thesis experiment, competitive baselines, and measurements.
5. Add an experiment manifest that registers hypotheses, treatments, seeds,
   held-out conditions, compute budgets, and planned analysis.

## Agent runtime and inheritance research

- Local inference adapter with explicit model/template/sampling versions.
- Separate immutable genotype, lifetime state, and cultural stores.
- Observable tool/memory/message budgets and failure handling.
- Heredity and communication interventions, lineage-aware statistics, and
  population/compute-matched controls.
- Do not interpret a named trait or fixed prompt role as emergent specialization.

## Observation and Unity

- Observer application for population maps, trait distributions, communication,
  genealogy, and recorded playback.
- Unity viewer consumes the observer protocol without controlling the world clock.
- Optional UnityWorld adapter for experiments requiring physics/embodiment.
- Adapter correctness and reproducibility checks precede scientific use.

## Long-duration operations

- Bounded/rotated logs, compacted snapshots, disk quotas, and retention policy.
- Crash/power-loss recovery tests, monitoring, run-level cost accounting.
- Durable artifact storage and explicit experiment stop conditions.
- Soak tests before claims of year-long unattended reliability.

No background experiment, daemon, paid service, or scheduled task is established
by this initialization.
